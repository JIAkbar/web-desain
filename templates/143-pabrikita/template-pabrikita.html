FAQ

Pertanyaan yang sering muncul.

Belum terjawab? Insinyur kami siap berdiskusi langsung di pabrikmu.

Apakah mesin lama tanpa PLC bisa terhubung?

Bisa. Kami memasang sensor arus jepit dan penghitung sederhana pada mesin lama, tanpa membongkar panel listrik. Data langsung masuk ke perhitungan OEE.

Berapa lama pemasangan untuk satu lini?

Rata-rata dua hari kerja per lini, termasuk pelatihan operator. Produksi tidak perlu berhenti; pemasangan dilakukan saat pergantian shift.

Apakah data produksi tetap di pabrik?

Pilih sesuai kebijakanmu: cloud di pusat data Indonesia, atau server di lokasi pabrik pada paket Grup. Data bisa diekspor kapan saja.

Bisa terhubung ke ERP yang sudah dipakai?

Ya. Order produksi, konsumsi bahan, dan hasil produksi disinkronkan dua arah lewat API atau berkas terjadwal.

Bagaimana jika internet pabrik putus?

Gateway menyimpan data hingga 7 hari dan mengirim ulang otomatis. Papan andon di lantai produksi tetap berjalan secara lokal.
